# CodeJudge Data Integrity Audit - Part 3

This project contains database integrity validation, auditing, and repair planning for the CodeJudge dataset.

Contents:

* Import validation
* Primary key and uniqueness audit
* Foreign key integrity checks
* Domain and rule validation
* Repair planning
* Safe repair scripts using staging tables

The objective is to identify inconsistent, duplicate, invalid, or orphaned records and safely propose corrective actions.
